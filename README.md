# Пет-проектик по анализу данных.
## Использование.
### Интерфейс 1: Исходные данные.
- При запуске появляется окно с начальными данными из таблицы *financial_data.db*.
- В этом окне имеются 4 кнопки: "Добавить", "Изменить", "Удалить" и "Сохранить в DataFrame".
  > **Добавить** - Добавляет новую строку в таблицу.
  
  > **Изменить** - Изменение в выбранной пользователем ячейке.
  
  > **Удалить** - Удаляет всю строку.
  
  > **Сохранить в DataFrame** - Эквивалент слова "Далее". Сохраняет таблицу в формат *DateFrame*, что позволяет проще работать с этой таблицей в дальнейшем и производить необходимые расчеты.
### Интерфейс 2: Результаты.
  > **Note:** Советую сразу открывать этот интерфейс в полноэкранном режиме.
- В левой части экрана отображаются все посчитанные коэффициенты за каждый год: *Финансовый риск*, *Маневренность*, *Финансирование*, *Независимость*, *Финансовая устойчивость*. Последние два столбца: Абсолютные изменения и Относительные изменения показывают изменения за весь промежуток времени.
  
- Снизу расположены 3 кнопки: "(выберите коэфффициент)", "Круговая диаграмма" и "Гистограмма".
  > **(выберите коэффициент)** - Выпадающий список, в котором можно выбрать один из предложенных выше коэффициентов. При выборе одного из них в правой части интерфейса появится график динамики изменений выбранного коэффициента за данный промежуток времени.
  
  > **Круговая диаграмма** - Диаграмма относительных изменений выборки за данный промежуток времени. *Строится по абсолютным значениям относительных изменений*

  > **Гистограмма** - Гистограмма, которая показывает динамику коэффициентов за первые 4 года. *Даже если дано > 4 лет*. Это сделано в целях компактности и наглядности.
